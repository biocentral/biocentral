Welcome to the biocentral! Biocentral provides a rich ecosystem for connecting biomedical data and machine learning.
It lets you work with your data where and how you want it: via a **python library** (API),
**directly in your terminal** (CLI) or via a rich frontend, our integrated research environment (IRE / GUI).

## Module Overview

These docs provide an overview of how you can use the *biocentral modules* via all three possible ways. For more
details, click on the module names in the sidebar.

### Embeddings

For machine learning, data needs to be provided in a machine-informative way. Machine learning models, such as
protein language models (pLMs), can represent biomedical entities (such as proteins) in a meaningful way. These
representations are called [embeddings](/docs/embed).
