### Summary

- **Model name:** `LightAttentionSubcellularLocalization`

- **Protocol:** `residues_to_class`

### Outputs

#### subcellular_localization

- **Description:** Protein subcellular localization
- **Output type:** `per_sequence`
- **Value type:** `str`

| Class | Meaning |
| --- | --- |
| `Cell_membrane` | Protein is localized to the cell membrane |
| `Cytoplasm` | Protein is localized to the cytoplasm |
| `Endoplasmatic_reticulum` | Protein is localized to the endoplasmic reticulum |
| `Golgi_apparatus` | Protein is localized to the Golgi apparatus |
| `Lysosome_or_Vacuole` | Protein is localized to lysosomes or vacuoles |
| `Mitochondrion` | Protein is localized to mitochondria |
| `Nucleus` | Protein is localized to the nucleus |
| `Peroxisome` | Protein is localized to peroxisomes |
| `Plastid` | Protein is localized to plastids |
| `Extracellular` | Protein is secreted outside the cell |
