---
title: UdonPred
description: Residue-level intrinsic disorder scoring using TriZOD outputs.
---

### Summary

- **Model name:** `UdonPred`
- **Task:** Intrinsic disorder prediction
- **Protocol:** `residue_to_value`
- **Embedder:** `Rostlab/ProstT5`
- **Model size:** `1.1 MB`

### Usage

import { Tabs, Tab } from 'fumadocs-ui/components/tabs';

<Tabs items={['API', 'Desktop']}>
    <Tab value="API">
        Using the [biocentral Python API](https://github.com/biocentral/biocentral_api):

        ```python
        from biocentral_api import BiocentralAPI, BiocentralPredictionModel

        biocentral_api = BiocentralAPI().wait_until_healthy(max_wait_seconds=10)

        model_names = [BiocentralPredictionModel.UDONPRED]
        sequence_data = {
            "Seq1": "MMALSLALMM",
            "Seq2": "PRTEINMMALM",
            "Seq3": "PRTSSSLAMAM",
            "Seq4": "SEQWENCEAWMMWW",
        }
        result = biocentral_api.predict(model_names=model_names, sequence_data=sequence_data).run()
        print(result)
        ```

### Outputs

#### disorder_trizod

- **Description:** Disorder scores (TriZOD)
- **Output type:** `per_residue`
- **Value type:** `float`
