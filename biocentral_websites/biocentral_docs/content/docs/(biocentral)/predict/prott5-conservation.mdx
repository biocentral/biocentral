### Summary

- **Model name:** `ProtT5Conservation`
- **Task:** Protein residue conservation prediction (VESPA)
- **Protocol:** `residue_to_class`
- **Embedder:** `Rostlab/prot_t5_xl_uniref50`
- **Model size:** `926.7 KB`

### Outputs

#### conservation

- **Description:** Per-residue evolutionary conservation prediction
- **Output type:** `per_residue`
- **Value type:** `str`

| Class range | Label | Meaning |
| --- | --- | --- |
| `0` to `3` | Variable | Residue is evolutionarily variable |
| `4` to `6` | Average | Residue is equally conserved and variable |
| `7` to `8` | Conserved | Residue is evolutionarily conserved |
