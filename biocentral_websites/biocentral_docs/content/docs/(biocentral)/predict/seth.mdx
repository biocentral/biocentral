### Summary

- **Model name:** `Seth`
- **Task:** Predict nuances of residue disorder in proteins
- **Protocol:** `residue_to_value`
- **Embedder:** `Rostlab/prot_t5_xl_uniref50`
- **Model size:** `575.1 KB`

### Outputs

#### disorder_chezod

- **Description:** Disorder scores based on CheZOD Z-score interpretation
- **Output type:** `per_residue`
- **Value type:** `float`
- **Interpretation:** Values below `8` indicate disorder; values above `8` indicate order
