The `predict` module provides sequence-level, residue-level, and mutation-level inference for protein analysis.

### Model catalog overview

| Model | Primary task | Protocol | Output granularity |
| --- | --- | --- | --- |
| [TMbed](./tmbed) | Transmembrane topology prediction | `residue_to_class` | Per residue |
| [LightAttentionMembrane](./lightattention-membrane) | Membrane association classification | `residues_to_class` | Per sequence |
| [LightAttentionSubcellularLocalization](./lightattention-subcellular-localization) | Subcellular localization classification | `residues_to_class` | Per sequence |
| [Seth](./seth) | Disorder scoring (CheZOD-based) | `residue_to_value` | Per residue |
| [UdonPred](./udonpred) | Disorder scoring (TriZOD) | `residue_to_value` | Per residue |
| [BindEmbed](./bindembed) | Ligand-binding residue prediction | `residue_to_class` | Per residue |
| [ProtT5Conservation](./prott5-conservation) | Residue conservation estimation | `residue_to_class` | Per residue |
| [ProtT5SecondaryStructure](./prott5-secondary-structure) | Secondary structure prediction (3-state and 8-state) | `residue_to_class` | Per residue |
| [VespaG](./vespag) | Variant effect prediction | `residue_to_class` | Mutation |
| [ExoTox](./exotox) | Exotoxin classification | `sequence_to_class` | Per sequence |

### Capability groups

- **Membrane and localization:** TMbed, LightAttentionMembrane, LightAttentionSubcellularLocalization
- **Disorder and conservation:** Seth, UdonPred, ProtT5Conservation
- **Structure and binding:** ProtT5SecondaryStructure, BindEmbed
- **Variant and functional phenotype:** VespaG, ExoTox

### Common metadata fields

Each model page includes:

- scientific scope and prediction target,
- protocol and output schema,
- class legend or numeric value ranges,
- model and training data references,
- licensing and citation links.
