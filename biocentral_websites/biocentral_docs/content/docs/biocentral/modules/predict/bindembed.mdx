title: BindEmbed
description: Per-residue ligand-binding propensity prediction across ligand classes.
---

### Summary

- **Model name:** `BindEmbed`
- **Task:** Binding residue prediction for multiple ligand classes
- **Protocol:** `residue_to_class`
- **Embedder:** `Rostlab/prot_t5_xl_uniref50`
- **Model size:** `2.6 MB`

### Outputs

#### metal

- **Description:** Per-residue binding affinity for metal
- **Output type:** `per_residue`
- **Value type:** `str`

| Class | Meaning |
| --- | --- |
| `M` | Residue binds to metal |
| `-` | Residue does not bind to metal |

#### nucleic

- **Description:** Per-residue binding affinity for nucleic acids
- **Output type:** `per_residue`
- **Value type:** `str`

| Class | Meaning |
| --- | --- |
| `N` | Residue binds to nucleic acids |
| `-` | Residue does not bind to nucleic acids |

#### small

- **Description:** Per-residue binding affinity for small organic molecules
- **Output type:** `per_residue`
- **Value type:** `str`

| Class | Meaning |
| --- | --- |
| `S` | Residue binds to small organic molecules |
| `-` | Residue does not bind to small organic molecules |
